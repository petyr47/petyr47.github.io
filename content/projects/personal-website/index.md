## Description

I have always wanted to build a simple website like this to post some articles and just use as an online portfolio of some sorts. However, since I am not generally a Frontend Web Developer, I have not been able to, until **AI**.

I chose to use AI to write the code for this project but not design it since I already liked the designs and simplicity of existing Hugo Blog themed websites and I like the Markdown formatting language.

Hosted on Github Pages for now, because it's free, eventually it will be hosted on a custom domain. They are deployed automatically when the ```main``` branch is updated using Github Actions.
